Invoke the `research` skill with the Skill tool and follow it exactly.

`research` answers a verifiable fact — is this package maintained, does this API
still exist, what is the current version, what is the known trap — and reports
dated sources. It never chooses between competing approaches and never edits
`docs/PRD.md`, Part 2 or a task file. For "which approach should we take" — where
more than one mechanism genuinely fits — use `idea-arena` instead; it researches
each alternative and adjudicates.
