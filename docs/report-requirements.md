# Project report — official format requirements

Transcribed verbatim on 11 September 2026 from
<https://itcodefair.cdu.edu.au/data-innovation-challenge-requirement/>.

**This page is linked as the "Requirement Link" from both the Data Innovation Challenge page
and the AI Challenge page.** The file naming rule below is written for the Data Challenge
only; AI Challenge teams should confirm their prefix with the organisers.

---

## Submission deliverables

The requirement page lists four deliverables, which is **more than the two listed in the
"Competition process" section of the challenge pages**. Build for all four.

1. Data analysis report and background research
2. 5-minute presentation slide deck
3. Interactive prototype solution
4. Python-based solution (`.py` files or Jupyter Notebooks; no restrictions on Python
   packages)

> The challenge page itself asks only for "1. Project report, 2. Source code (Python with
> remarks for the key steps) with a README file containing reproducing instructions". The
> requirement page is the more demanding of the two and adds the slide deck and the
> interactive prototype. The safe reading is the union of both lists: report, slides,
> interactive prototype, Python source with remarks, and a README with reproduction
> instructions.
>
> Note also that the requirement page says a **5-minute** slide deck while Challenge Day is a
> **10-minute pitch plus 5-minute Q&A**. Prepare for the 10-minute slot and keep a 5-minute
> cut.

## Report file rules

| Rule | Requirement |
|---|---|
| File type | PDF only |
| Length | Maximum 8 pages, excluding title page, references and appendices |
| Word count | ~2,500 words (guideline only, not a strict limit) |
| Page setup | A4, continuous page numbering; header and footer must include Team Number and Page Number |
| Font, title | 20 pt bold |
| Font, section headings | 14 pt bold |
| Font, body text | 11 pt regular |
| Font, captions and references | 10 pt |
| Typeface | Calibri or Arial |
| File name | `DataChallenge_Team xx(number)_Report.pdf` |

## Required structure

1. **Title page** — report title, team number, members with roles, date, challenge name.
2. **Summary (150–250 words)** — an overview of the report: the problem or gap, approaches,
   key findings, impacts (ethical, cultural, community), and recommendations or solutions.
3. **Main body**
   - **Introduction** — background, purpose, scope, communications, and so on.
   - **Methodology** — data sources, techniques, design.
   - **Findings** — key results, supporting evidence.
   - **Discussion** — ethical, cultural and community impacts.
   - **Recommendations** — actionable recommendations for government, industry or community
     stakeholders.
4. **References** — official articles, data, resources, peer-reviewed publications, and tools
   with links.
5. **Appendices (if applicable)** — AI usage declaration, source code, dataset links.

## Two things worth noticing in the structure

- **"Discussion" is defined as the ethics section.** The template does not leave ethical,
  cultural and community impact as an optional subsection; it is the entire discussion. That
  matches "ethical considerations" being one of the six judging criteria.
- **An AI usage declaration is expected in the appendix.** Declare what was generated with AI
  assistance rather than leaving it to be inferred.
