# Reports — research harvested from unattended runs

## What goes here

Research output from agents you started and did not sit and watch: a deep
research pass, a "is this library maintained" sweep, a competitor teardown, a
spike writeup.

The point is not tidiness, it is limits. Idle quota is wasted quota. Start the
research when you cannot supervise it, let it write here, and process it later
when you can actually think about the answer.

## Rules

- One file per question, named after the question, dated.
- Say which model and when, at the top. A finding ages; a finding without a
  date cannot be judged.
- A report is input, never a decision. Bringing it into `docs/PRD.md` or Blueprint
  is a separate, deliberate step.
- `research` (the skill) answers a question live and hands the decision back;
  it does not write here. This folder is for the longer unattended runs.
