## Objective

Make the audit log the Phase 2 reasoning record: a real recorded-at clock beside the
dataset decision day, a batch version on every signature, and record kinds for human-set
fields, intake, backlog promotion and visit-plan decisions.

## Execution Guide

- Every record gains `recorded_at: datetime` (wall clock, timezone-aware, ISO 8601 on disk) and keeps `day: date` (dataset). Rename nothing else; `signed_at`/`at` stay for Phase 1 readers and are written equal to `recorded_at`.
- `SignOff` gains `batch_version: int`, `today_job_ids: tuple[str, ...]` (the proposed batch) beside `ranked_job_ids` (the full order), `decision: "approve" | "defer"`, `audit_ref: str` (`f"{day:%Y%m%d}-v{batch_version}"`).
- New kinds: `HumanSet(day, job_id, field, value, actor, reason)`, `Intake(day, job_id, provider, model, prompt_version, latency_s, validation, status)`, `Promotion(day, job_id, displaced_job_id, reason)`, `PlanDecision(day, batch_version, action: "accept" | "edit" | "reject" | "suggestion_accept", detail: str, reason: str)`. Register each in `_KIND_OF`; `read` tolerates unknown kinds by skipping with a warning count rather than raising.
- `export_rows` emits readable column names (`kind, decision_day, recorded_at, audit_ref, job_id, previous_weighting, new_weighting, reason, signer, detail, hash`) where `hash` is `sha256` of the canonical JSON line, first 12 hex chars. `override_rate` groups by `day`.
- `seed_audit.py` regenerates `data/audit/sample.jsonl` with the new fields from the fixed seed; wall-clock values in the sample are derived from the seed (`day` at 09:00 Darwin time plus a seeded offset) so the file is reproducible. Say so in the script's remark.
- Tests: round-trip for every kind; `recorded_at` is timezone-aware and never equal to midnight of `day` in the seeded sample; `audit_ref` format; unknown kind skipped; export column set fixed; `hash` stable across two reads.
